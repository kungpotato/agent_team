# Mandatory Agile Sprint Ceremony Governance Policy

When working with this project or executing sprint milestones, all agents MUST strictly follow the 8-phase sprint ceremony protocol:

1. `validation` (Room 2) - PO presents story card; Dev & Architect validate AC.
2. `grooming` (Room 1) - Analyze edge cases, test vectors, and estimate Fibonacci points.
3. `planning` (Room 5 Boardroom) - Decompose DAG waves and distribute work.
4. `working` (Desks) - Active coding with live progress HUDs.
5. `demo` (Room 3) - Demonstrate completed feature live.
6. `uat` (Room 2) - Formal UAT Verification & Sign-Off (MANDATORY).
7. `release` (Room 4) - Canary release and production deployment.
8. `retro` (Room 5 Boardroom) - Sprint Retrospective & Lessons Learned.
